How saving works here

  • GitHub (recommended on this host): connect your website's repository below, then press Save changes as usual — the editor commits your new content.json and the site updates automatically after redeploy.
  • Built-in server: if this editor runs on a server (like the demo on localhost), Save changes writes directly to the site — no GitHub needed.
  • Export: always available — downloads content.json to upload manually anywhere.

Connect GitHub

Create one at github.com → Settings → Developer settings → Fine-grained tokens (or classic). Give it Contents: Read and write on this repository only. The token is stored only in this browser — anyone with access to this browser can update the site.

Before you rely on Save

  • Make sure Vercel (or your host) is set to auto-deploy on push to the branch above — then every Save goes live on its own.
  • Keep the repository reachable: the editor commits only content.json (and photos you upload) — it never touches any other file.
